# 🤝 Contributing to RĀY OS

Thank you for your interest in contributing to **RĀY — AI-Powered Pocket Olfactory Scanner & Synthesizer**!

RĀY is built in public across a 14-day rapid prototyping sprint. We welcome hardware designers, embedded engineers, machine learning enthusiasts, perfumers, and developers of all backgrounds.

---

## 🧭 How You Can Contribute

- **Firmware (`/firmware`):** Optimize GC9A01 graphics, BME688 sensor sampling algorithms, BLE telemetry, or power management.
- **Hardware & CAD (`/hardware`):** 3D print ergonomics, star chassis aesthetic designs, resin-friendly snaps, or custom PCB schematics.
- **Olfactory Machine Learning (`/ml-model`, `/scent-library`):** Contribute baseline VOC logs, calibrate aroma clusters, or train Edge Impulse models.
- **Mobile Companion App (`/mobile-app`):** Build out the Scent Vault UI, BLE GATT client, and digital scent sharing features.

---

## 🌿 Development Workflow

1. **Fork the Repository:** Click the **Fork** button on GitHub.
2. **Clone your Fork:**
   ```bash
   git clone https://github.com/<your-username>/ray-os.git
   cd ray-os
   ```
3. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make Your Changes:** Follow clean C++, Dart/Flutter, or Markdown conventions.
5. **Commit with Clear Messages:** Follow [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat:` for new features or hardware implementations
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `chore:` for maintenance
6. **Push and Open a Pull Request:**
   ```bash
   git push origin feature/your-feature-name
   ```
   Open a Pull Request describing your motivation and test results!
